# Site IA Conecta+

Site estático da IA Conecta+ (Garde Inteligência Empresarial). HTML + Tailwind via CDN, sem build.

- `index.html` — landing page
- `segmentos.html` — página de segmentos (`/segmentos`)
- `segmentos/<setor>.html` — páginas por setor (`/segmentos/educacao`, `/saude`, `/imobiliario`, `/logistica`, `/franquias`, `/varejo`, `/financeiro`, `/industria`)

Deploy: importar o repositório na Vercel (framework "Other", sem comando de build).
